# Spaceship Clash

O projeto foi feito para o projeto integragdor da UNISA do curso Engenharia de Software na matéria de Linguagem de Programação no 4º semestre .

O projeto foi pensado e desenvolvido com o objetivo de entreter e divertir os usuários, utilizando uma abordagem lúdica para promover um aprendizado envolvente. A ideia central do projeto é a criação de um jogo simples e eficaz, no qual um objeto se locomove utilizando o movimento do mouse. Esse objeto deve passar entre obstáculos verticais, e, ao superá-los, um contador é acionado para registrar a pontuação do jogador, indicando o quão longe ele conseguiu chegar. Cada obstáculo superado aumenta a pontuação, incentivando o jogador a superar seu próprio recorde em cada nova tentativa.

O desenvolvimento desse jogo permitiu um contato maior com a programação e a criação de um aplicativo interativo, proporcionando uma experiência de aprendizado prática e instigante. Além de oferecer entretenimento, o projeto foi uma oportunidade de aplicar conceitos de lógica e design de forma divertida e intuitiva.
